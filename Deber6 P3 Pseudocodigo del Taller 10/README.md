## Descripción

Este directorio contiene el pseudocódigo del Taller 10, desarrollado fielmente a partir del diagrama de flujo del proceso de **Evaluación Docente**, el cual comprende:

- Planificación y comunicación del proceso de evaluación al docente.
- Aplicación de la encuesta a los estudiantes y verificación de su llenado.
- Recolección y análisis de las respuestas (identificación de fortalezas y debilidades).
- Evaluación del desempeño del docente según las expectativas (otorgamiento de recompensa o reunión para plan de mejora).
- Entrega del informe con observaciones/sugerencias al docente y fase final de seguimiento.

## Cómo ejecutar / verificar el pseudocódigo

El pseudocódigo está escrito en formato **PSeInt** (perfil flexible / estándar). Para verificar su funcionamiento:

1. Abrir el software **PSeInt**.
2. Copiar el código del archivo `pseudocodigo.md` en el editor.
3. Ejecutar paso a paso o presionar **F9** para comprobar la lógica de salida en la consola.
4. (Opcional) Hacer clic en el icono de **Dibujar Diagrama de Flujo** (`F7`) para verificar la correspondencia visual con el gráfico original.
